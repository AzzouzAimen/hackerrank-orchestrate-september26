# Development input binding and contract coverage

The offline builder `code/prototype/build_semantic_dev_inputs.py` bound all 14 frozen development cases to the exact `extraction_experiment.py` request format. Each saved `.request.json` is the UTF-8 `json.dumps(body).encode('utf-8')` byte sequence that `call_model` would send as its JSON body: same system prompt, case/evidence/schema text, image PNG data URLs, model, and settings. Nothing was sent. The full SHA-256, selected IDs, source paths, available event context, explicit message currency codes, and reviewed target gaps are recorded in `development_runtime_inputs_v1/manifest.json`. The builder does not read profiles, sample labels, requests, or holdout annotations.

The following evaluates each important meaning in annotation v3 against its **saved request**. Hash prefixes identify the bound body; the manifest holds full hashes. “Fully expressible” means the seven-type schema can serialize the meaning using identifiers and currency available in that body; it does not mean the current v3 `required_contract_facts` are already a sound scoring reference.

**Current coverage:** nine cases are fully expressible from their bound inputs (user_16, user_03, user_06, user_12, user_28, user_04, user_20, user_229, user_22). Five retain target or currency limitations (user_10, user_26, user_18, user_23, user_14). This is an input/schema coverage assessment, not a model score. Development references remain `assistant_draft`; v3 has empty required lists for user_12/user_04 despite newly bound support, and has unsupported target assumptions for user_26/user_14. Do not freeze or score it as-is.

The builder intentionally adds only IDs already named in the frozen split or v3 development draft. It does not add profile/home currency or invented stream descriptors. The event context in the manifest is derived from included CSV rows for inspection; it is not injected as a separate prompt field. Image SHA-256 values prove attachment bytes came from the selected PNG files. `--check` recomputes all 14 requests and the manifest byte for byte.
